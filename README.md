# Deflectometry
Implementación de técnica de deflectometría, obtención de mapas de fase y amplitud. 

# Archivos:
-cam.py : Driver para manejo de cámara Thorlabs, mediante librería UC480.py
-patterns.py : Generador de patrones sinosoidales a proyectar
-deflectometry.py : Métodos para adquisición de imagen, obtención de mapas de fase (unwrapping incluid) y amplitud.
